# Touch Grass Bible - Documentation Index

This folder now includes a generated `src/` scaffold that summarizes the codebase file by file.

- `docs/src/README.md` - entry point for source-code docs
- `docs/src/core.md` - app entry, Bible models, settings, screens, and tests
- `docs/src/external.md` - framework, workspace, palette, events, and UI primitives
- `docs/src/plugins.md` - feature plugins and their tests
- `docs/src/platform-shells.md` - platform adapters, Electron shell, web shell, and static assets

It also includes an improvement review scaffold based on a codebase-wide pass.

- `docs/improvements/README.md` - index and prioritized roadmap

- `docs/improvements/framework.md` - workspace, command palette, event, UI, and CSS improvements
- `docs/improvements/plugins.md` - plugin-specific enhancements and cross-plugin opportunities
- `docs/improvements/platform.md` - web, Electron, Capacitor, packaging, and offline improvements
