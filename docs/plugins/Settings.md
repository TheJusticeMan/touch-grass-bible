# `SettingsPlugin` — In-App Settings

**File:** `src/plugins/Settings.ts`

---

## Overview

`SettingsPlugin` provides an in-app settings panel via the command palette. It offers configuration toggles, data export/import, factory reset, and app version information.

---

## Plugin Class

```typescript
export default class SettingsPlugin extends Plugin {
  async onload(): Promise<void> {
    this.registerPalette(() => new SettingsCategory(this.app.commandPalette, this), "settings");
  }
}
```

---

## `SettingsCategory`

**Category ID:** `"settings"`

This category uses only `CMD` (command) and `toggleCMD` (toggle) items registered in `onTrigger()`. It has no dynamic command list (`getCommands` always returns `[]`).

### Available Commands

#### Debug Console (Toggle)

```
[●] Debug console
```

A `toggleCMD` that:

- Shows the current state (`enableLogging`)
- On toggle: updates `app.console.enabled`, `app.settings.enableLogging`, and saves settings

#### Download Settings

```
Download settings
Download your current settings as a JSON file
```

- Calls `app.saveSettings()` first to ensure data is current
- Calls `app.downloadFile("TouchGrassBibleSettings.json", app.settings)`
- Creates a browser download of the complete settings JSON

#### Upload Settings

```
Upload settings
Upload a JSON file to update your settings
```

- Opens a file picker (`.json` files only)
- Merges uploaded settings over `DEFAULT_SETTINGS`
- Merges uploaded bookmark data into existing bookmarks via `addData()`
- Saves merged settings

#### Reset Settings

```
Reset settings
Reset settings to default values
```

- Uses `commandPalette.confirm()` to show a confirmation dialog
- On confirm: resets `app.settings` to defaults, recreates `VerseRef.Bookmarks`, saves

#### App Info (Read-Only)

```
Touch Grass Bible
Version: 3.1.1
Author: Justice Vellacott
Built: ...
License: MIT
...
```

Displays info from `src/info.json` (generated by the build system). No action on click.

## `CMD` and `toggleCMD`

These are helper classes from `src/external/Comands.ts` for building command palette items:

```typescript
class CMD {
  constructor(defaultCMD: /* container */)
  setName(name: string): this
  setDescription(text: string): this
  on("_click", handler): this   // Triggered when item is selected
}

class toggleCMD extends CMD {
  setValue(state: boolean): this  // Set initial checked state
  on("change", (newValue: boolean) => void): this
}
```

---

## Settings Persistence

Settings changes made through this category are immediately saved:

```typescript
// Toggle:
this.app.settings.enableLogging = enabled;
this.app.saveSettings();  // Immediate save

// Upload/Reset:
this.app.settings = { ... };
this.app.saveSettings();  // Immediate save
```

This is different from most settings changes (bookmarks, notes) which use the 5-second debounce.
