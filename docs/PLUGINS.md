# Plugins Reference

This document provides an overview of each built-in plugin.

## Bookmarks (plugins/Bookmarks.ts)

**Purpose**: Save and organize favorite verses

**Features**:

- Add verses to custom tags
- Date-based automatic tagging (history)
- Command palette integration
- Verse action button

**Categories**:

- `BookmarkCategory` - List bookmark tags
- `VerseListCategory` - List verses in a tag

## Notes (plugins/Notes/)

**Purpose**: Personal notes on specific verses

**Features**:

- Per-verse notes
- Search notes
- Export notes

## Journal (plugins/Journal/)

**Purpose**: Continuous reading journal with history

**Features**:

- Automatic date-based entries
- Reading history tracking
- Journal panel view

## Search (plugins/Search.ts)

**Purpose**: Search Bible text

**Features**:

- Full-text search
- Book/chapter filters
- Fuzzy matching

## Topical Bible (plugins/TopicalBible.ts)

**Purpose**: Browse topics and their verses

**Features**:

- Topics from OpenBible.info
- Cross-references by topic

## Translations (plugins/Translations.ts)

**Purpose**: Switch between Bible versions

**Features**:

- KJV, YLT, ASV built-in
- Easy switching
- Per-translation settings

## TSK (plugins/TSK.ts)

**Purpose**: Treasury of Scripture Knowledge cross-references

**Features**:

- Enhanced cross-references
- Command palette integration
- Verse context menu

## Settings (plugins/Settings.ts)

**Purpose**: Application configuration

**Features**:

- Debug console toggle
- Settings import/export
- Reset to defaults
- Keyboard shortcuts help

## AI (plugins/AI.ts)

**Purpose**: AI-powered Bible study assistant

**Features**:

- Natural language queries
- Verse explanation
- Study guidance

## Share (plugins/Share.ts)

**Purpose**: Share verses externally

**Features**:

- Generate shareable links
- Multiple platforms
- Copy to clipboard
